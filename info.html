Games

For my Y10 Digitech class, I created this game in Microsoft MakeCode Arcade.
It was inspired by a lot of games that have a really satisfying gameplay loop.
For example, Unbeatable, a game where you have to hit the enemies as they appear, and the game gets faster and faster as you progress.
I wanted to make a game that was similar, but with a unique twist.
And I thought about the game Ultrakill, a game that while it isnt a rhythm game, it has a very satisfying gameplay loop too,
So I made a rhythm game where you have to Parry the Enemies as they appear.
Because I think its interesting when you arent strong enough to fight an enemy, but you can still survive by dodging and parrying.
The games named Parry Core. The link is here. And here, and also here. If you press UDLRUDLRUUDDLRLR, you unlock the secret arcade mode. (Based on arcade machines).
